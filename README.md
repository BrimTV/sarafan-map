# Сарафанное древо — денежные разборы

Карта реферальной сети: кто кого привёл, до 7 колена.

- **[index.html](https://brimtv.github.io/sarafan-map/)** — рабочая версия для команды:
  имя с фамилией, vk-id, ссылки «открыть диалог ВК», суммы донатов по каждому.
  Поиск понимает имя, фамилию и id — в любом порядке, «е» вместо «ё» тоже;
  Enter листает найденных по кругу.
- **[public.html](https://brimtv.github.io/sarafan-map/public.html)** — обезличенная:
  только имена, id порядковые, ссылок на профили нет. Для показа вовне.

Страница самодостаточная: один HTML, без зависимостей и запросов наружу.
Открывается с телефона: перетаскивание — обзор, два пальца — масштаб,
двойное касание — вернуться к общему виду.

Обновляется автоматически раз в 3 часа (`numerolog/sarafan_map/publish.py`
в рабочем репозитории, launchd `com.zvezdun.sarafan-map`). Если данные не
менялись, пересборки и коммита не происходит. Время среза — в шапке карты.

`robots.txt` и `noindex` закрывают страницу от поисковых систем: ссылка
работает у всех, кто её знает, но в выдачу Google/Яндекса не попадает.
